# 🚀 The 90-Day Startup Launch Checklist
## From Idea to MVP — A Practical Guide by Crelligent & Co.

---

## Introduction

Starting a business is exciting, but without a clear roadmap, it's easy to get lost in the chaos. This checklist is designed to take you from a raw idea to a working Minimum Viable Product (MVP) in 90 days.

We've distilled insights from building multiple startups and helping dozens of founders launch their products. Follow this step-by-step, and you'll avoid the costly mistakes that kill 90% of startups.

**Let's build something great.**

---

## 📅 Phase 1: Validate (Days 1-30)
### "Make sure you're solving a real problem"

### Week 1: Problem Discovery
- [ ] Write down the problem you're solving in ONE sentence
- [ ] List 3 types of people who have this problem
- [ ] Identify where these people hang out (online/offline)
- [ ] Join 5 communities where your target users are active

### Week 2: Customer Conversations
- [ ] Reach out to 20 potential users for interviews
- [ ] Conduct at least 10 problem interviews (15-20 min each)
- [ ] Document pain points, workarounds, and willingness to pay
- [ ] Create a "Problem Validation Summary" (1-page)

### Week 3: Competitive Analysis
- [ ] List 5-10 competitors or alternatives
- [ ] Identify their strengths and weaknesses
- [ ] Find your unique angle or positioning
- [ ] Document your differentiation in 2-3 bullet points

### Week 4: Value Proposition
- [ ] Write your value proposition statement
- [ ] Create a simple landing page (1 page, 1 CTA)
- [ ] Drive 100+ visitors to the page
- [ ] Collect at least 30 email signups (validates interest)

**✅ Phase 1 Complete Checklist:**
- Problem validated with real users?
- At least 30 people on your waitlist?
- Clear positioning against competitors?

---

## 🎨 Phase 2: Design (Days 31-50)
### "Design the experience before you build"

### Week 5: User Journey Mapping
- [ ] Map the ideal user flow (signup → value → retention)
- [ ] Identify the "aha moment" — when users see value
- [ ] List core features (max 3-5 for MVP)
- [ ] Prioritize ruthlessly: What's essential vs. nice-to-have?

### Week 6: Wireframing
- [ ] Sketch low-fidelity wireframes (paper or Figma)
- [ ] Review wireframes with 3-5 potential users
- [ ] Iterate based on feedback
- [ ] Finalize the core screens

### Week 7: Branding & Visual Design
- [ ] Define brand colors (2-3 colors max)
- [ ] Choose fonts (1 for headings, 1 for body)
- [ ] Design a simple logo (or use a text logo)
- [ ] Create high-fidelity mockups for core screens

**✅ Phase 2 Complete Checklist:**
- Clear user journey defined?
- Wireframes validated with users?
- Visual identity ready?

---

## 💻 Phase 3: Build (Days 51-75)
### "Ship fast, iterate faster"

### Week 8-9: Development Setup
- [ ] Choose your tech stack (keep it simple)
- [ ] Set up version control (GitHub)
- [ ] Set up project management (Notion, Trello, Linear)
- [ ] Define sprint goals (what to ship each week)

### Week 10: Core Feature Build
- [ ] Build the #1 core feature (the "aha moment" feature)
- [ ] Keep scope tight — resist feature creep
- [ ] Test as you build (don't wait until the end)
- [ ] Get early feedback from 2-3 beta users

### Week 11: Integration & Polish
- [ ] Connect authentication (login/signup)
- [ ] Set up database and basic API
- [ ] Add minimum necessary UI polish
- [ ] Ensure mobile responsiveness

**✅ Phase 3 Complete Checklist:**
- Core feature working?
- Users can sign up and experience value?
- No major bugs blocking usage?

---

## 🚀 Phase 4: Launch (Days 76-90)
### "Get it in front of real users"

### Week 12: Pre-Launch Prep
- [ ] Set up analytics (Google Analytics, Mixpanel, or Posthog)
- [ ] Create onboarding flow (first-time user experience)
- [ ] Write launch announcement (email, social media)
- [ ] Prepare support channel (email, chat, or WhatsApp)

### Week 13: Soft Launch
- [ ] Invite your waitlist (30+ people)
- [ ] Monitor for bugs and feedback
- [ ] Fix critical issues in real-time
- [ ] Collect testimonials from early users

### Week 14: Public Launch
- [ ] Announce on LinkedIn, Twitter/X, and communities
- [ ] Submit to Product Hunt (optional but powerful)
- [ ] Email your network with a personal ask
- [ ] Celebrate! You shipped a product. 🎉

**✅ Phase 4 Complete Checklist:**
- MVP live and accessible?
- At least 50 real users signed up?
- Feedback loop in place for iteration?
