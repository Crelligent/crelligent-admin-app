                   ▼
┌─────────────────────────────────────────────────────┐
│  QUALIFY                                            │
│  Score < 40: "You need Foundry Starter"             │
│  Score 40-70: "You need Foundry Growth"             │
│  Score > 70: "You need Foundry Scale"               │
│  → In-app notification + email sequence             │
└──────────────────┬──────────────────────────────────┘
                   ▼
┌─────────────────────────────────────────────────────┐

**Automation Triggers:**
- VeloDesk sign-up → Welcome email (Day 0)
- PMF Score generated → "Here's what your score means" email (Day 0)
- Score < 40 → "Your startup needs a system" nurture sequence (Day 1, 3, 7)
- No action after 14 days → Re-engagement email with case study
- Discovery call booked → Prep email with questionnaire

5. Invite to technical discovery call
6. If qualified → pilot proposal within 2 weeks

### Lead Scoring Model

Every lead gets a score based on engagement signals. Scored in `bisuite-app` Growth Module.

| Signal | Points | Category |
| :--- | :--- | :--- |
| Visited website | +5 | Awareness |
| Downloaded white paper | +10 | Interest |
| VeloDesk sign-up | +15 | Product engagement |
| PMF Score generated | +20 | High intent |
| Attended webinar/event | +15 | Interest |
| Opened 3+ emails | +10 | Engagement |
| Replied to outreach | +20 | Warm lead |
| Booked discovery call | +30 | Sales-ready |
| Requested proposal | +40 | Hot lead |

| Score Range | Status | Action |
| :--- | :--- | :--- |
| 0–20 | **Cold** | Nurture with content |
| 21–50 | **Warm** | Targeted outreach |
| 51–80 | **Hot** | Discovery call |
| 81+ | **Sales-Ready** | Proposal within 48hrs |
