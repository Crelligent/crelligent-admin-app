## Phase 1: Solo + Freelancers (Month 1–6)

**Objective:** Land your first 3 paying clients, deliver excellently, and build proof. Revenue funds everything.

### Team
| Role | Who | Cost |
| :--- | :--- | :--- |
| **Founder** | You | Covers all leadership: sales, architecture, delivery, marketing |
| **Freelance Developer** | On-demand, per project | Built into project pricing |
| **Freelance Designer** | On-demand, per project | Built into project pricing |
| **Freelance Content Writer** | Monthly retainer | $300–$800/mo |
| **Virtual Assistant** | Monthly retainer | $500–$1,000/mo |
| **Bookkeeper** | Monthly retainer | $300–$500/mo |

### Operating Model

**Your Weekly Rhythm:**

| Day | Block 1 (Morning) | Block 2 (Afternoon) |
| :--- | :--- | :--- |
| **Mon** | Publish Foundry content (X + LinkedIn) | Sales outreach, follow-ups |
| **Tue** | Client delivery work | Freelancer check-ins, code/design review |
| **Wed** | Publish Edge content (LinkedIn) | Architecture, system design |
| **Thu** | Client delivery work | Proposals, invoicing, admin |
| **Fri** | Publish Enterprise content (LinkedIn) | Discovery calls, pipeline review |
| **Sat** | Platform development (VeloDesk/BI Suite) | Strategy, learning |

**How You Deliver an Engagement:**
```
1. Win the deal → You run discovery, scope, and proposal
2. Design the system → You produce the system architecture
3. Brief freelancers → Clear specs, acceptance criteria, timeline
4. Freelancers execute → Dev builds, designer designs
5. You QA everything → Architecture compliance, quality check
6. You deliver to client → Presentation, handoff, documentation
7. Collect final payment → Invoice, follow-up, testimonial ask
```

## Phase 2: First Hires (Month 6–12)

**Objective:** Hire your first 3–4 full-time people to free you from execution so you can focus on sales and architecture.

### Team

| Role | Type | Trigger to Hire |
| :--- | :--- | :--- |
| **Founder** | Full-time | Still covers CEO, Sales, Architecture |
| **Full-Stack Developer** | Full-time hire #1 | 2+ concurrent projects |
| **Content Strategist** | Full-time hire #2 | Revenue > $10K/mo consistently |
| **Project Manager** | Full-time hire #3 | 3+ active engagements |
| **UX/UI Designer** | Full-time hire #4 | Design needs constant (every project) |
| Freelancers | On-demand | Embedded eng, data, overflow |
| VA + Bookkeeper | Retained | Continue |

### Operating Model Shift

| Before (Phase 1) | After (Phase 2) |
| :--- | :--- |
| You write all content | Content Strategist runs the calendar |
| You manage freelancers | PM manages delivery and timelines |
| You build + review code | Full-Stack Dev builds, you review architecture only |
| You design everything | Designer produces all assets |
| **You do everything** | **You sell and architect** |

**Your new role: Founder = Chief Architect + Chief Revenue Officer**

### Revenue Targets

| Vertical | Target | Activity |
| :--- | :--- | :--- |
| **Foundry** | 2 Growth engagements ($15K each) | Scaled content, VeloDesk PLG |
| **Enterprise** | 1 Full ESRE™ ($150K–$250K) | From Diagnostic upsell or new |
| **Edge** | 1 Pilot ($25K–$50K) | First ABM conversion |

**Phase 2 Revenue Target: $100K–$150K in 6 months**

├── Full-Stack Developer

├── Project Manager
